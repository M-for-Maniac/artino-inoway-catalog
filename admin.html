LOCAL CATALOG MANAGEMENT

Catalog Manager

Manage catalog records and prepare images. The image tool now uses the catalog item itself, so you do not need to know item IDs, categories, filenames or sequence numbers when adding images.

1. Record→2. Image→3. Review→4. Publish
Simple rule: keep your original photos wherever they already are on your computer. In the Image Intake section, paste the full local path, choose the catalog item, choose what the image is for, and copy the generated VS Code command. The tool handles the filename, folder, resizing, sequence number and catalog linking automatically.

IMAGE INTAKE

Add an image to a catalog item

This is intentionally simplified. You should not need to understand filenames or sequence numbers.

Where should the original image go?
Anywhere on your computer. For example: C:\Artino Photos\New Project\IMG_4837.jpg. Do not copy it into the repository first.
The system will automatically create the next filename
You do not need to enter:
  • Item ID — selected automatically from the catalog item.
  • Category — inherited automatically from the selected item.
  • Title — inherited automatically from the selected item.
  • Sequence — the tool finds the next available number automatically.
  • Filename — generated automatically.
After adding a new item or category: click Download JSON and replace the repository's data/catalog.json with that downloaded file before running the image command. The image tool reads the repository's JSON, so this keeps the local tool synchronized with your latest edits.
Publishing rule: never put a GitHub personal access token in admin.html. Your existing Git authentication is used by the local publishing script.
